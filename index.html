COMMON QUESTIONS

First payment FAQ

Is USDT the same as USDC?

No. They are separate stablecoins. Confirm which one the sender will use before sharing an address.

What does TRC20, ERC20, Base, Polygon, or Solana mean?

Those names refer to blockchain networks. The sending and receiving network must match.

Can I use an exchange address to receive a payment?

Sometimes, but only if the exchange currently supports deposits for that exact stablecoin and network in your location.

Should I send a small test payment first?

For large or unfamiliar transfers, a small test transaction can help confirm the asset, network, and address before sending the full amount.
